# IEEE paper build

The manuscript uses the official IEEE conference class in US Letter, two-column mode.

Build from this directory with a TeX distribution that provides `IEEEtran`:

```powershell
tectonic main.tex
```

Submission note: the authors supplied names and mentor, but no institutional affiliation,
city, country, email addresses, ORCID identifiers, conference name, or funding statement.
Add only verified metadata required by the selected venue before submission. The manuscript
is limited to five pages including references.

The prose, tables, and architecture diagram were written specifically from this repository's
implementation and recorded run artifacts. Published methods are cited at the point where
their ideas or models are discussed. Before submission, the target conference should run its
required similarity screening and PDF eXpress validation; a local review is not a substitute
for those venue services.
